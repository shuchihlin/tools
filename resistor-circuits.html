▶ 分壓電路（Voltage Divider）
Vout = Vin × R2/(R1+R2)
R1=R2 → Vout = Vin/2
調整比值 → 任意電壓

工作原理：
兩個電阻串聯，電流相同，電壓依電阻比例分配（歐姆定律）。

中間節點電壓即 Vout，接 ADC 可量測。

實際應用：將 R2 換成 NTC 熱敏電阻，Vout 隨溫度變化 → 溫度感測器。換成光敏電阻（LDR）→ 光線感測。這是感測器電路的基礎結構。

ADC 輸入 溫度感測 電壓縮放
核心定律
歐姆定律 V = IR
典型應用
感測器偏壓、ADC 前端、電壓縮放
設計注意
負載阻抗需遠大於 R1+R2
▶ LED 限流電阻
R = (Vcc - Vf) / If
Vf = LED 順向電壓
If = 工作電流（一般 10~20mA）

工作原理：
LED 本身沒有限流能力，直接接電源會因電流過大瞬間燒毀。

電阻消耗多餘電壓（Vcc - Vf），將電流限制在安全範圍。

計算範例：Vcc=5V，Vf=2V，If=20mA
R = (5-2) / 0.02 = 150Ω

LED 驅動 指示燈 GPIO 保護
核心功能
消耗多餘電壓，限制電流
常見 Vf
紅/黃 2V，藍/白/綠 3~3.5V
設計原則
寧大勿小，避免過流燒毀
▶ 上拉 / 下拉電阻（Pull-up / Pull-down）
上拉：空接→HIGH（VCC）
按下→LOW（GND）

下拉：空接→LOW（GND）
按下→HIGH（VCC）

工作原理：
GPIO 在沒有明確驅動時，輸入端會浮接（floating），讀值不穩定，可能亂跳 0/1。

上拉電阻：將線路拉到 VCC，確保空接時為 HIGH；按鈕按下接地變 LOW。

下拉電阻：將線路拉到 GND，確保空接時為 LOW；按鈕按下接 VCC 變 HIGH。

典型值 10KΩ：夠大不浪費電流，夠小不受雜訊干擾。

按鍵輸入 I2C 匯流排 開漏輸出
問題根源
浮接輸入讀值不穩定
典型阻值
4.7KΩ ~ 10KΩ
I2C 特別
SDA/SCL 必須加上拉電阻
▶ 運算放大器增益設定（反相放大器）
Vout = −(Rf/Rin) × Vin
增益 = −Rf/Rin
兩個電阻比值決定放大倍數

工作原理：
運算放大器本身增益極高（100dB+），靠兩個電阻的比值決定實際增益，這叫做負回授（Negative Feedback）。

Rin：輸入電阻，決定輸入阻抗。
Rf：回授電阻，決定放大倍數。

增益 = Rf/Rin（反相，輸出極性相反）。要改增益，只需換一顆電阻，不改 IC。

音頻放大 感測器放大 信號調理
核心概念
電阻比值 = 放大倍數
典型應用
麥克風放大、儀表放大、濾波器
設計彈性
換 Rf 即可改變增益，不換 IC
