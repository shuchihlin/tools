▶ 去耦電容（Decoupling Capacitor）
I = C × dV/dt
C 提供瞬間電流
穩定 VCC 電壓

工作原理：
IC 在切換時會瞬間吸入大電流，導致 VCC 電壓下降（電源噪聲）。

C2（100nF，緊鄰 IC）：高頻去耦，抑制 IC 自身產生的高頻切換噪聲，必須放在 IC 電源腳旁邊。

C1（100µF，大電容）：低頻儲能，補充電源線路上的電流不足，穩定整體電壓。

PCB 必備 每顆 IC 旁 EMI 抑制
核心特性

典型值
100nF 陶瓷 + 10~100µF 電解
擺放原則
100nF 盡量靠近 IC 電源腳
▶ RC 定時電路（555 Timer）
T = 0.7 × (R1+2R2) × C
f = 1/T
τ = RC（時間常數）

工作原理：
電容透過 R1+R2 充電至 2/3 VCC，555 觸發放電；再透過 R2 放電至 1/3 VCC，重新充電。

充電時間 = 0.7 × (R1+R2) × C
放電時間 = 0.7 × R2 × C

改變 R 或 C 即可調整頻率，電容決定時間尺度，這是 RC 定時的核心。

▶ 交流耦合電容（AC Coupling）
Xc = 1 / (2πfC)
f→0（DC）: Xc → ∞
f→∞（AC）: Xc → 0

工作原理：
電容的容抗 Xc 與頻率成反比：

DC（f=0）：Xc 無窮大 → 完全阻斷，直流無法通過。

AC（f高）：Xc 極小 → 交流信號幾乎無衰減通過。

應用：音頻放大器各級之間，隔離直流偏壓，只讓音頻信號傳遞。

選值原則
Xc 在工作頻率遠小於負載阻抗
▶ 整流濾波電容（Power Supply）
Vripple ≈ I / (f × C)
C 越大 → 漣波越小
→ DC 越平滑

工作原理：
橋式整流後輸出的是脈動直流（有漣波 ripple）。

大電容 C1 在電壓高時充電儲能，電壓下降時放電補充，將脈動波形填平，輸出平滑直流。

電容越大（1000µF~10000µF），漣波越小，輸出越穩定。這是所有線性電源的基本結構。
